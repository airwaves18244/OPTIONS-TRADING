# OPTIONS-TRADING — Учебный курс + лаборатория стратегий

Полноценная система для самостоятельного изучения торговли опционами в паре с **`optionslab`** —
Python-библиотекой для построения и анализа опционных стратегий. Обе части растут вместе: каждый
модуль курса объясняет понятия в уроке на Markdown, а затем делает их осязаемыми в Jupyter-ноутбуке,
работающем на этой библиотеке. К моменту, когда вы закончите курс, вы уже знаете и инструмент — а
инструмент лежит в основе будущего приложения-билдера/анализатора стратегий.

## Как пользоваться этим репозиторием

1. Сначала прочитайте `ROADMAP.ru.md` — это и есть рабочий процесс.
2. Проходите модули по порядку (`curriculum-ru/00-…` → `11-…`): читайте `lesson.md`, запускайте и
   меняйте `notebook.ipynb`, делайте `exercises.md` и переходите дальше только после того, как взяли
   выпускной барьер модуля.
3. Начиная с фазы 2 отыгрывайте изученное на бумажных сделках и ведите журнал (шаблон в модуле 10).
4. Отслеживайте прогресс в `TODO.md`.

## Быстрая проба

```python
from optionslab import strategies, analyzer, viz

# айрон кондор на 45 DTE по акции за $100: ноги заданы как (страйк, премия)
ic = strategies.iron_condor(
    long_put=(85, 0.55), short_put=(90, 1.10),
    short_call=(110, 1.05), long_call=(115, 0.50),
    expiry=45 / 365,
)
print(analyzer.summarize(ic, spot=100, vol=0.25))
viz.plot_payoff(ic)
```

## Дисклеймер

Этот проект — **учебный материал, а не финансовая рекомендация**. Опционы сопряжены со значительным
риском и подходят не каждому инвестору. Используемые здесь модели (Блэка — Шоулза — Мертона,
биномиальная, логнормальные оценки POP) — упрощения реальных рынков. Сначала торгуйте на бумаге;
никогда не рискуйте деньгами, потерю которых вы не можете себе позволить.
